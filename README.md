# Data Professional Survey Dashboard | Power BI

## Project Overview

This project analyzes survey responses from 630 data professionals to explore career trends, salary differences, programming language preferences, and job satisfaction within the data industry.

The dashboard was developed using Microsoft Power BI as part of a guided project by Alex The Analyst. This project provided hands-on experience with data cleaning, transformation, and visualization.

![Data Professional Survey Dashboard](Screenshot%202026-11-13%20163442.png)

## Tools Used

- **Microsoft Power BI** — Dashboard development and data visualization
- **Power Query** — Data cleaning and transformation

## Dataset

The dataset contains survey responses from individuals working in or pursuing careers in data-related fields.

The analysis focuses on:
- Job titles and average salaries
- Geographic distribution of survey respondents
- Favorite programming languages
- Industry representation
- Work-life balance and salary satisfaction

## Dashboard Features

The interactive dashboard includes:

- **Treemap:** Distribution of survey respondents by country
- **Bar Chart:** Average salary by job title
- **Column Chart:** Favorite programming languages
- **Donut Chart:** Industry distribution of respondents
- **Gauge Charts:** Average work-life balance and salary satisfaction
- **KPI Cards:** Total survey participants and average respondent age

## Key Findings

Based on the survey responses:

- **630 individuals** participated in the survey.
- The average age of respondents was **29.87 years**.
- Average work-life balance satisfaction was **5.74 out of 10**.
- Average salary satisfaction was **4.27 out of 10**.
- **Python** was the most frequently selected favorite programming language.

These findings reflect the survey sample and may not represent the entire data professional population.
